## Roles (maintainer's definition, apply everywhere)
- `user` = system admin: everything.
- `cnt` = central staff: sees data of ALL units, but only for the sections the admin granted in `admin.access`
  (controller ids). E.g. with `packages` access they see every unit's mid-term courses.
- `emp` = unit staff: only their own unit's data, and only sections in `access`.
- `broker`: only their own courses (`courses.broker._id`) and what hangs off them.
- `teacher`: only holding classes and the content of the courses/lessons where they are the teacher (or mentor). Nothing else.
- Guests must be sent to the LOGIN page for every protected action (not `access-denied`, which shows the menu).
